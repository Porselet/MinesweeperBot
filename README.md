# Minesweeper Bot (Сапёр-бот)

Автоматический бот для игры «Сапёр» (Minesweeper) на C# (.NET).
Бот делает скриншот окна игры, распознаёт состояние поля по шаблонам,
находит безопасные ходы с помощью логики и эмулирует клики мышью.

## Возможности

- Компьютерное зрение: распознавание клеток по шаблонам (пиксельное сравнение через LockBits).
- Логика Сапёра: базовые правила (открытие безопасных клеток, установка флагов).
- Умный рандом: если логика зашла в тупик, бот выбирает клетку с максимальным числом открытых соседей и избегает «опасных» зон (рядом с цифрами 4+).
- Паттерн 1-2-1: дополнительная эвристика для поиска мин и безопасных клеток.
- Эмуляция кликов: левая кнопка — открыть клетку, правая — поставить флаг.
- Автоперезапуск: после победы или поражения бот кликает по смайлику и начинает новую игру.
- Экстренная остановка: клавиша F12 мгновенно останавливает бота (работает глобально).
- Логирование: подробный лог с миллисекундами, матрицей поля и действиями бота.

## Требования

- ОС: Windows 10/11 (x64).
- .NET: .NET 10.0 SDK (или новее).
- Игра: классический «Сапёр» (winmine.exe), окно должно называться «Сапер» или «Сапёр».
- Visual Studio 2022/2026 (или любая IDE с поддержкой C#).

## Сборка

1. Клонируй репозиторий:
   git clone https://github.com/your-username/MinesweeperBot.git
   cd MinesweeperBot

2. Открой решение в Visual Studio.

3. Убедись, что в свойствах проекта включён «Разрешить небезопасный код» (AllowUnsafeBlocks = true), так как TemplateMatcher использует LockBits.

4. Собери проект:
   dotnet build

## Запуск

1. Запусти игру «Сапёр» (окно должно быть не свёрнуто).
2. Запусти бота:
   dotnet run
3. Через 3 секунды бот начнёт играть.
4. Нажми F12, чтобы остановить бота в любой момент.

## Как это работает

1. Захват экрана (ScreenCapture.cs)
Используется Win32 API BitBlt для быстрого копирования содержимого окна игры.
Это работает в 5 раз быстрее, чем Graphics.CopyFromScreen (55 мс против 320 мс).

2. Распознавание клеток (TemplateMatcher.cs)
Каждая клетка (16x16 пикселей) сравнивается с эталонами из папки templates/.
Используется LockBits для прямого доступа к памяти (это в 15-20 раз быстрее, чем GetPixel).
Порог совпадения — 85%.

3. Логика (Solver.cs)
- Правило флага: если вокруг цифры N ровно N закрытых клеток, все они — мины.
- Правило безопасного хода: если вокруг цифры N уже стоит N флагов, все остальные закрытые соседи — безопасны.
- Умный рандом: если логика зашла в тупик, выбирается клетка с максимальным числом открытых соседей и минимальным числом «опасных» соседей (цифры 4+).

4. Клики (InputSimulator.cs)
Win32 API SetCursorPos + mouse_event для эмуляции левой и правой кнопки мыши.

5. Экстренная остановка
Win32 API GetAsyncKeyState проверяет нажатие F12 глобально (даже если окно игры активно).
Бот останавливается на середине серии кликов.

## Производительность

| Этап                      | Время     |
|---------------------------|-----------|
| Скриншот                  | ~55 мс    |
| Распознавание (256 клеток)| ~6 мс     |

## Настройка

Параметры в Program.cs:

const int StartX = 15;          // Отступ слева до первой клетки
const int StartY = 101;         // Отступ сверху до первой клетки
const int CellSize = 16;        // Размер клетки (16x16)
const int DelayAfterClick = 20; // Пауза после клика (мс)
const int DelayBetweenTurns = 50; // Пауза между ходами (мс)

Важно: координаты StartX, StartY и CellSize зависят от версии игры.
Если бот не видит поле, откалибруй эти значения вручную.

## Калибровка

1. Запусти бота с параметрами по умолчанию.
2. Открой screenshot_with_grid.png — там зелёная сетка.
3. Если сетка не совпадает с клетками игры, измени StartX, StartY, CellSize вручную.

## Известные ограничения

- Только Windows: используется Win32 API.
- Классический «Сапёр»: координаты рассчитаны на стандартную версию winmine.exe (16x16).
  Для других версий нужна калибровка.
- Паттерн 1-2-1 работает только для горизонтальных и вертикальных последовательностей
  (диагональные не проверяются).
- Вероятностный анализ не реализован (бот использует «умный рандом» в тупиках).
